# Local Microservice Dev Stack

Небольшой локальный контур для разработки микросервисов: одной командой поднимает чистые PostgreSQL-базы и Apache Kafka, а сами микросервисы остаются запущенными из IDE для полноценной отладки.

Основной сценарий на Windows:

```powershell
.\scripts\dev-stack.ps1 reset
```

или двойной клик по `start.bat`.

Команда `reset` удаляет старые Docker volumes, создаёт чистую инфраструктуру, ждёт health checks и заново создаёт набор БД из `.env`. Первый запуск автоматически формирует `.env` со случайными локальными паролями.

Подробное описание и архитектура приведены в основном [README.md](README.md).
